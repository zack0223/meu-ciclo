Meu Ciclo 🌸

Aplicação de acompanhamento do ciclo menstrual.

Funcionalidades

- Cálculo do ciclo menstrual.
- Estimativa da ovulação.
- Estimativa da janela fértil.
- Guia das fases do ciclo.
- Orientações de bem-estar.
- Sistema de acesso por assinatura Hotmart.

Tecnologias

- Python
- Gradio
- FastAPI
- SQLite
